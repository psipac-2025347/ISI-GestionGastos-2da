# ISI-Gestion-Gastos

Aplicación web para el control de ingresos, gastos y fondo de emergencia personales.

## Tecnologías

- **Frontend**: Angular 22 (standalone)
- **Backend**: Express + TypeScript
- **Base de datos**: PostgreSQL con Prisma 7
- **Gestor de paquetes**: pnpm
